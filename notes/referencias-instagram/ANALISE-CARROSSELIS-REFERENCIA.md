## 3. Dinâmica de Deslizamento

### Como Conectar Slides para Manter o Flush

| Técnica | Usada por | Eficácia |
|--------|-----------|----------|
| **Barra de progresso** (1/3, 2/3) | Todos | ✅ Essencial |
| **Setas laterais** (< >) | @insany.co, @luisfelipe.design | ✅ Alta |
| **Frase contínua** (continua→) | @insany.co | ✅ Média |
| **"Próximo slide"** | Raro | ⚠️ Não usar |
| **Números grandes** | @karinesackt | ✅ Boa |

### Padrões de Transição

#### Padrão: Frase Incompleta (@insany.co)
```
Slide 1: "O erro que faz com que você"
Slide 2: "perca usuários é..."

```

#### Padrão: Progressão Visual
```
Slide 1: Problema

```

#### Padrão: Lista Espalhada

## 5. Regras de Design para Stitch

### Componentes Recomendados

1. **Template Capa**
   - [ ] Fundo escuro (#000000 ou #1a1a1a)
   - [ ] Título 48-72pt, bold, branco
   - [ ] Subtítulo opcional em tom mais claro
   - [ ] Logomarca opcional no canto

2. **Template Slide de Conteúdo**
   - [ ] Área principal para imagem/print (60% altura)
   - [ ] Título superior (24-32pt)
   - [ ] Corpo em lista ou parágrafo (16-20pt)
   - [ ] Indicador de slide no canto inferior

3. **Template Slide de Resultado**
   - [ ] Métrica em destaque (48-60pt)
   - [ ] Ícone de crescimento (↑ ou seta)
   - [ ] Contexto explicativo abaixo

4. **Template Slide de CTA**
   - [ ] Frase de impacto centralizada
   - [ ] Ícone de salvamento/floppy
   - [ ] Instrução clara de ação

### Paleta Recomendada

| Uso | Cor |
|-----|-----|
| Fundo principal | #000000 ou #1a1a1a |
| Texto primário | #FFFFFF |
| Texto secundário | #A0A0A0 |
| Destaque/CTA | #FF6B6B (vermelho) ou #4ECDC4 (verde) |
| Métricas | #00D084 (verde) |

## 6. Regras de Copy

### Estrutura de Capa

```
[GANCHO] - Frase de impacto ou pergunta
  ↓
[SUBTÍTULO] - O que a pessoa vai aprender/fazer
```

Exemplos:
- "O erro que faz você perder usuários"
- "Não é só sobre fazer bonito"
- "Redesign: +127% conversões"

### Estrutura de Corpo

- **Bullet points**: 3-5 itens por slide
- **Uma ideia por slide**: Não sobrecarregar
- **Texto curto**: Máx 2-3 linhas por item
- **Jargão zero**: Explicar termos técnicos

### Estrutura de Fechamento

- Slide final sempre com CTA
- "Salva para não perder" = melhor taxa
- Incluir CTA também na legenda

---

## 7. Checklist de Carrossel de Alto Desempenho

- [ ] Capa com gancho claro (erro, resultado ou quebra de crença)
- [ ] Indicador de progresso visível (1/5, 2/5...)
- [ ] 3-5 slides apenas (não mais que 7)
- [ ] Uma ideia por slide
- [ ] Prints reais ou mockups de qualidade
- [ ] Pelo menos um slide com resultado/métrica
- [ ] CTA claro no último slide
- [ ] CTA na legenda também
- [ ] Hashtags relevantes (3-5 máx)
